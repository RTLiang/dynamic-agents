# Dynamic Agents

[English](README.md) · [简体中文](README.zh-CN.md)

通过原生 Mac 仪表盘和系统实时活动，查看 coding agent 的工作状态。

**[下载最新 DMG](https://github.com/RTLiang/dynamic-agents/releases/latest)**

支持 **Pi、Claude Code、Codex App / CLI、Cursor 和 VS Code Copilot** 的生命周期 Hook。显示运行中、等待输入和近期完成的会话，点击会话时激活其宿主 App。

## 要求与安装

- Apple silicon、**macOS 27.3+** 和 Python 3。
- Agent 已启用生命周期 Hook。Pi 需要支持 agent_settled 事件的扩展 API。客户端版本、组织策略和 Hook 信任设置会影响事件发送。

1. 下载并打开 DMG，把 **DynamicAgents.app** 拖到 **Applications**，推出磁盘映像，再打开安装后的 App。
2. 如果 macOS 阻止首次启动，在 **系统设置 → 隐私与安全 → 仍要打开** 中确认。发布包仅保留运行必需的本地 ad-hoc 签名，没有 Developer ID 签名或公证。
3. 打开 **设置 → Agent Hook → 管理 Agent Hook**，安装所需适配器，然后重启客户端或重新加载扩展。Pi 使用 **/reload**；Codex 需要检查并信任新增 Hook。
4. 开始一轮任务，让 Agent 发送首个事件。已有适配器如显示“可更新”，请使用新版 App 更新共享 helper。

安装保留无关配置并创建本地备份。安装和移除立即生效。激活 App 无需辅助功能或自动化权限。

## 会话状态

默认排序为 **运行中 → 等待输入 → 已完成 → 空闲 → 未知**，支持搜索、筛选和手动排序。

| 状态 | 含义 |
| --- | --- |
| 运行中 | Agent 正在处理一轮任务。 |
| 等待输入 | 暂停等待你的权限、回答或决策。 |
| 已完成 | 一轮执行近期结束，不代表整个项目完成或所有目标成功。 |
| 空闲 | 会话可用，当前无工作，也无有效完成提醒。 |
| 未知 | 无法验证当前工作，不计入运行中数量。 |

完成提醒默认保留 **10 分钟**，可在设置中改为 **1–1440 分钟**。查看结果不重置计时。过期后，可用会话变为空闲，已关闭会话消失。Pi 取消执行后变为空闲，错误不会生成完成提醒。能够通过结构化元数据识别的 Codex 内部记忆、标题和子代理维护不会作为用户会话显示。

## 打开宿主 App

双击行、选中后按 Return，或点击菜单和实时活动中的会话，激活已经运行的宿主 App。窗口、标签页和对话选择由宿主保持。

优先通过进程祖先链识别宿主；对于脱离终端祖先链的 CLI，可使用 Hook 环境中已知 App 的提示识别终端 App，但无法据此识别多路复用器内部的特定客户端。宿主不明、已退出或有歧义时明确报错。验证仍在运行的 CLI 即使没有已知宿主，也可以继续监控。

## 实时活动与语言

实时活动仅显示 **运行中和近期完成**。等待输入和空闲会话保留在仪表盘和菜单。无符合条件的会话时隐藏实时活动，监控继续；隐藏菜单栏图标或关闭仪表盘也不会停止监控。

App 与 Widget 支持 **英文和简体中文**，跟随系统语言，或在 **系统设置 → 通用 → 语言与地区 → 应用程序** 中单独选择。会话标题和项目名称保持原文。

## 隐私与更新

本地记录包括哈希会话 ID、状态、项目目录名、有长度限制的标题、时间、进程祖先链及可选的宿主 App 提示，不保存提示词、工具参数/结果或完整工作目录路径。Codex 分类仅读取有界的首行会话元数据，标题来自有大小限制的会话标题索引。

可选更新检查访问本仓库公开的 GitHub Releases API，打开发布页面，不上传会话内容，也不自动安装。**从 0.1.x 升级时请手动下载 DMG**，旧版更新检测仅识别 ZIP。

没有会话时，检查适配器和信任状态、重新加载客户端，再开始新一轮任务。打开失败时确认宿主仍在运行并发送新的生命周期事件。没有实时活动时，检查开关及运行中或近期完成的会话。
