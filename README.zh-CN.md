# Dynamic Agents

[English](README.md) · [简体中文](README.zh-CN.md)

不用盯着每个终端，也能知道 coding agent 进行到哪一步。

Dynamic Agents 是一款原生 Mac 应用，用来查看哪些编程会话正在运行、等待你处理，或者刚有结果。通过系统实时活动，可以从菜单栏区域快速回到对应会话。

**[下载最新版本](https://github.com/RTLiang/dynamic-agents/releases/latest)**

## 使用要求

- 带实时活动的版本需要 **Apple silicon Mac 和 macOS 27.3 或更新系统**。
- 监控 herdr 内的会话，需要本机安装并运行 [herdr](https://herdr.dev/)。
- 监控 herdr 之外的桌面会话，需要 Python 3，以及客户端支持的生命周期 Hook；这种模式可以独立于 herdr 使用。

桌面适配器支持 Claude Code、Codex App / CLI、Cursor Agent，以及 VS Code 的共享 Copilot 运行时。能否收到事件取决于客户端版本、组织策略和 Hook 信任设置。普通聊天窗口不在监控范围内。

## 安装

1. 从 [Releases 页面](https://github.com/RTLiang/dynamic-agents/releases/latest) 下载 ZIP，解压后将 **DynamicAgents.app** 移到**应用程序**。
2. 打开 App。如果 macOS 阻止运行，进入**系统设置 → 隐私与安全性**，找到关于 Dynamic Agents 的提示，选择**仍要打开**并确认。需要校验下载时，可使用发布页的 SHA-256 文件。
3. 使用终端跳转时，在**隐私与安全性 → 辅助功能**中启用 **Dynamic Agents**，并允许它针对所选终端发出的自动化请求。

发布包由本机编译，不使用 Apple Developer ID 证书，也不做公证。Apple silicon 二进制保留系统运行所需的本地 ad-hoc 签名，这不代表经过 Apple 验证。首次放行、辅助功能与自动化是三个独立的系统控制项。

## 开始监控

**herdr 内的会话**

先启动 herdr，再在其中运行 coding agent，然后打开 Dynamic Agents。App 会自动发现本机 herdr 客户端。存在多个会话或终端窗口时，可通过齿轮按钮选择具体目标。

**桌面客户端及 herdr 之外的会话**

进入**连接设置 → Agent 集成 → 管理集成 → 桌面客户端**，安装需要的适配器，重启对应客户端，并完成它的 Hook 权限审核。Codex 需要在自身的 Hook 设置中信任这些定义。已有的其他 Hook 会保留。

## 看懂列表

默认顺序为 **运行中 → 需要输入 → 已完成 → 空闲**；暂时无法确认状态的会话显示为“未知”，排在最后。也可以搜索、按状态筛选，或手动点击表头排序。

| 状态 | 含义 |
| --- | --- |
| **运行中** | Agent 正在处理这一轮请求。 |
| **需要输入** | 当前工作因权限、问题或决策而暂停，等待你处理。 |
| **已完成** | 最近一轮执行已结束，可以回来查看结果；不代表整个项目已经做完，也不保证所有要求都成功达成。 |
| **空闲** | 编程会话仍然可用，但没有任务在执行，也没有仍在保留期内的完成提醒。新建会话、被中断的会话也可能空闲。 |
| **未知** | App 暂时无法验证状态，不会将它计为正在运行。 |

完成提醒默认保留 **10 分钟**。在连接设置中，可将**完成后保留**设为 **1–1440 分钟**。查看结果不会重新计时。提醒到期后，仍可用的会话变为空闲；已经关闭的桌面会话则从列表消失。

列表用于呈现编程会话和最近的完成结果。空白 Shell 标签页、已经关闭的桌面空闲会话、普通聊天，以及 Codex memory consolidation、自动生成标题等内部任务，都不应占据列表。

## 回到工作位置

双击列表行，或者选中后按 **Return**；也可以通过菜单栏菜单或实时活动选择会话。

对于 herdr，App 会在你选定的终端客户端中定位**已有页面**，保留其他客户端的当前页面，不新建窗口或标签页。支持 **Ghostty 1.3+、iTerm2 和 Apple Terminal**。直接定位需要 herdr 的常规侧栏可见，并保持鼠标捕获开启；布局不受支持或无法确定目标时，会说明原因，不会擅自切换到其他客户端。

对于一般桌面客户端，App 会打开实际观察到的宿主应用；并非所有编辑器都支持精确定位某一条对话。

## 实时活动与语言

实时活动只显示**运行中的会话和最近完成的会话**。空闲及等待输入的会话仍可在主窗口和菜单中查看。没有符合条件的会话时，实时活动自动隐藏，后台监控继续进行。

App 和实时活动支持 **English 与简体中文**，跟随系统语言，也可以在**系统设置 → 通用 → 语言与地区 → 应用程序**中单独为 Dynamic Agents 选择语言。收起时的数量、展开后的状态、操作提示和辅助功能文字都会使用对应语言；你自己的会话标题和项目名保持原样。

可以在设置中隐藏菜单栏图标，监控不会停止。关闭主窗口也不会退出 App。需要恢复窗口或图标时，从 Dock 重新打开即可。

## 看不到会话或无法打开时

- **没有会话：**检查 herdr 是否运行，或桌面适配器是否安装、受信任；开始新一轮任务，让客户端发送事件。
- **选错 herdr 窗口：**在连接设置中选择准确的**打开方式**和 **herdr 窗口**。原窗口关闭后需要重新选择，App 不会悄悄跳到其他地方。
- **更新后无法跳转：**打开辅助功能设置。如果 Dynamic Agents 的旧条目已开启但仍不生效，移除该条目，再添加“应用程序”里的当前 App。密码或 Touch ID 由你本人完成。
- **Hook 提示可更新：**用当前版本的 App 更新适配器，保持 App 与复制出去的脚本版本一致。旧 App 无法判断被单独替换的脚本实际上更新。
- **没有实时活动：**在 App 中启用实时活动，允许 macOS 需要的权限，并确认至少有一个运行中或最近完成的会话。

## 隐私与更新

会话状态保留在本机。桌面 Hook 保存生命周期元数据、哈希后的会话标识、项目目录名和进程祖先信息，不保存提示词、工具参数或对话正文。Codex 来源分类只读取有大小限制的会话元数据头。

可选的更新检查会请求本仓库公开的 GitHub Releases API，只打开发布页面，不会自动安装更新，也不会上传会话内容。可在设置中关闭自动检查。
