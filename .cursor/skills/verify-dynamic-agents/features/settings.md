# Settings

## User behavior

Settings control completion retention, menu visibility, Agent Hooks and update checks. Save persists edits; Cancel discards them. Hook installation/removal is immediate and independent of Save/Cancel.

## Executable journey

Run control settings after launch. It edits the completion-window-minutes field, presses Save, reopens, checks the value and presses Cancel. Run control hooks for the manage-agent-hooks entry and nested manager. All preferences belong to the unique disposable bundle.
