# Menu bar

The menu uses the same Hook feed and status priority as the dashboard. Session actions activate the host App. Hiding the status item and closing the dashboard keep monitoring running.

The isolated control menu command reports status-item presence only. For menu-specific changes, open the owned extras menu, check synthetic titles and status order, exercise an App action, then toggle visibility in Settings and verify the same monitoring process continues. A status-item presence check alone is not a full interaction journey.
