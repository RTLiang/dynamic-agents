# Agent hooks

## User behavior

Pi, Claude Code, Codex, Cursor and Copilot adapters copy the current helper and preserve unrelated client configuration. Pi also installs a copied TypeScript lifecycle extension. Outdated resources show Update Available.

## Executable journey

Run control hooks. Require five UI installs, visible outdated state after controlled divergence, one UI update clearing every shared-helper prompt, successful controlled reports and five UI removals returning the dashboard to zero. Inspect hooks-installed.json, hooks-removed.json, the action transcript and hook-doctor output. The Node script scripts/test-pi-hook.mjs separately loads the copied Pi extension and verifies final settlement, cancellation, errors and shutdown through the Python reporter.

## Boundaries

Installation in disposable configuration does not establish a vendor's hook trust. Test that separately when required. A passing isolated helper comparison cannot clear a mismatch in the user's installed App.
