# Dynamic Agents 0.2.1

## English

Fixes Codex background memory workers appearing as user sessions. Those workers can be ephemeral and have no rollout metadata; the previous filter treated missing metadata as a user session.

- Count Codex only after matching session metadata verifies a user source. Keep verified user classification across sparse events.
- Exclude unverified/ephemeral workers at both the reporter and App collector. A later valid user header can restore a previously unverified session.
- Updating the Codex adapter reconciles old reports and clears false completion reminders. Verified projects or titles containing “memory” remain supported.

**Update the App, then update the Codex adapter in Settings → Agent Hooks.** User-created ephemeral sessions without verifiable source metadata are also excluded. No title or project-name blacklist is used.

Apple silicon, macOS 27.3+, Python 3. Locally built DMG with the required ad-hoc execution signature; no Developer ID or notarization.

## 简体中文

修复 Codex 后台记忆整理会话被计入用户任务的问题。这类内部线程可能不落盘，没有普通会话元数据；此前缺失元数据时仍被放行。

- Codex 仅在匹配的元数据确认用户来源后才计入，后续稀疏事件保留已验证分类。
- 上报脚本与 App 读取端双重排除未验证的临时线程；之后取得有效用户元数据时可恢复正常显示。
- 更新 Codex 适配器时重新核对旧记录，清除误生成的完成提醒；标题或项目名含 memory 的已验证正常会话不受影响。

**更新 App 后，请在“设置 → Agent Hook”中更新 Codex 适配器。** 用户主动创建但没有可验证来源元数据的临时会话也暂不显示。本修复不使用标题或项目名黑名单。

需要 Apple silicon、macOS 27.3+ 和 Python 3。DMG 在本地构建，仅保留运行必需的 ad-hoc 签名，无 Developer ID 签名或公证。
