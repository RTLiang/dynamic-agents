# Dynamic Agents 0.1.2

Fixes the integration manager's truncated **herdr / Desktop Clients** selector in both English and Simplified Chinese. The native segmented selector now sits inside the sheet content with enough space for both labels. Switching retains each panel's state, and hidden panels cannot receive input.

Locally built for Apple silicon, macOS 27.3+. CI checks code only. No Developer ID certificate or notarization; the app retains its required local ad-hoc signature. Quit the previous version before replacing the App in Applications. If the previous Accessibility grant stops working, remove that entry and add the current App again.
