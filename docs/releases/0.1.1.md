# Dynamic Agents 0.1.1

A locally built native release for **Apple silicon, macOS 27.3+**.

- Faster jumps to existing herdr pages without opening the Go to chooser. Ghostty 1.3+, iTerm2 and Apple Terminal keep other clients on their current pages. A visible normal sidebar, enabled mouse capture and distinguishable workspace/tab/agent labels are required; ambiguous layouts return an error.
- Running sessions appear first, followed by Needs Input, recent Completed sessions and available Idle sessions. A completed turn is a temporary reminder, not permanent project history. Closed desktop sessions disappear after the reminder expires.
- Live Activities carry the app's English or Simplified Chinese language into compact counts, expanded statuses, action hints and accessibility text.
- Codex memory/title maintenance is excluded from session counts when its source metadata identifies it as internal work.
- A user-oriented English README and a complete Simplified Chinese guide.

Download the ZIP, unzip it and move **DynamicAgents.app** to **Applications**. If macOS blocks first launch, use **System Settings → Privacy & Security → Open Anyway**. Terminal navigation needs **Accessibility** and the terminal's **Automation** permission. After an update, a stale Accessibility entry may need to be removed and the current App added again; complete password or Touch ID prompts yourself.

The archive was built and uploaded from a local Mac, not CI. It uses **no Apple Developer ID certificate and no notarization**; Apple silicon executables retain the minimum local ad-hoc signature required to run. A SHA-256 file and source/build manifest accompany the ZIP.

本版在本机编译，适用于 **Apple silicon 和 macOS 27.3 或更新系统**。

- 更快定位 herdr 的已有页面，跳转时不打开 Go to 选择页面。支持 Ghostty 1.3+、iTerm2 和 Apple Terminal，保留其他客户端的页面；需要常规侧栏可见、鼠标捕获开启，且工作区、标签页和 Agent 标识能够区分目标，含糊的布局会明确报错。
- 默认依次显示运行中、需要输入、最近已完成和仍可用的空闲会话。“已完成”表示最近一轮执行结束；提醒到期后，已关闭的桌面会话不再留在列表里。
- 实时活动的数量、状态、操作提示和辅助功能文字使用 App 所选的英文或简体中文。
- 对来源元数据明确标识的 Codex memory、标题生成等内部任务进行过滤。
- 重写默认英文 README，附完整简体中文使用指南。

下载 ZIP，解压后将 **DynamicAgents.app** 移到**应用程序**。首次被阻止时，进入**系统设置 → 隐私与安全性 → 仍要打开**。终端定位需要**辅助功能**及对应终端的**自动化**权限。更新后若旧授权不生效，移除 Dynamic Agents 的旧条目，再添加当前 App，密码或 Touch ID 由用户本人完成。
