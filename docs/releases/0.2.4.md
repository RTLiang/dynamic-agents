# Dynamic Agents 0.2.4

## English

Explain and recover from Live Activity startup failures when monitoring is enabled and sessions are Working. A real cold-background launch reproduced ActivityAuthorizationError.visibility (code 7, “Target is not foreground”); bringing the App to the foreground then succeeded.

- Reconcile a cached activity with the system registry. Confirm a missing entry after a propagation grace period before recreating it.
- Preserve the enabled preference when an activity ends and recover automatically. Explicit dismissal and switching the activity off still keep it off.
- For visibility rejection, show a clear instruction to open the App and pause requests while it remains in the background. Returning to the foreground retries immediately, with backoff for visibility propagation or other transient failures. Hook monitoring continues independently of ActivityKit operations.
- Add **Restart Live Activity** in Settings and on the error banner for an explicit recreation when the system reports an activity but its presentation is missing.
- Add lifecycle diagnostics containing state/count/error information without session titles or conversation content.

Verified with 17 production-controller scenarios using a transport double, plus actual ActivityKit end recovery, manual recreation, empty-feed hiding and new activity creation while the main App is already in the background. These checks do not claim that every intermittent system presentation failure has been reproduced.

Locally built DMG for Apple silicon, macOS 27.3+.

## 简体中文

处理“监控已开启、会话处于 Working，但实时活动偶尔未出现”的启动与恢复问题。真实后台冷启动已复现 ActivityAuthorizationError.visibility（code 7，Target is not foreground）；将 App 切回前台后创建成功。

- 将缓存活动与系统列表核对，在传播宽限期后连续确认活动丢失，再重新创建。
- 活动结束后保留启用设置并自动恢复；主动关闭活动或关闭开关后仍保持关闭。
- 可见性限制导致创建被拒绝时，明确提示打开 App，并暂停后台重复请求；回到前台后立即重试，可见性传播延迟和其他临时错误使用退避重试；Hook 监控不再等待 ActivityKit 操作。
- 在设置和错误提示中增加 **重新显示实时活动**，供系统仍报告活动存在但界面缺失时手动重建。
- 增加仅含状态、数量和错误信息的生命周期诊断，不记录会话标题或对话内容。

已通过 17 个使用传输替身的生产控制器场景，并验证真实 ActivityKit 的结束恢复、手动重建、空列表隐藏，以及主 App 已在后台时首次创建。上述验证不代表所有系统偶发展示问题均已复现。

提供本地构建的 DMG，适用于 Apple silicon、macOS 27.3+。
