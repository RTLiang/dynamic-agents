# Dynamic Agents 0.2.0

## English

- Monitor agents through lifecycle hooks only, with adapters for Pi, Claude Code, Codex App / CLI, Cursor and VS Code Copilot. The herdr integration and connection settings have been removed.
- Session actions now activate the already running host App. They leave window, tab and conversation selection with that App, and need no Accessibility or Automation permission.
- Pi uses its final settlement event to avoid premature completion during retries. Codex internal/background work remains excluded when identified by structured metadata.
- Keep native system Live Activities, configurable completion reminders, English and Simplified Chinese.
- Install using the **DMG**: open it, drag DynamicAgents.app to Applications, eject and launch. This release provides no ZIP.

**Upgrading:** download this DMG manually if using 0.1.x; the older updater accepts ZIP assets only. Open Settings → Agent Hooks → Manage Agent Hooks and update existing adapters. Install Pi if needed and use /reload. Review Codex hook trust settings.

Apple silicon, macOS 27.3+, Python 3. Pi requires the extension API with agent_settled. Built and uploaded locally with the required ad-hoc execution signature, without Developer ID or notarization. If macOS blocks first launch, use System Settings → Privacy & Security → Open Anyway.

## 简体中文

- 改为仅通过生命周期 Hook 监控，支持 Pi、Claude Code、Codex App / CLI、Cursor 和 VS Code Copilot；移除 herdr 适配和连接设置。
- 点击会话仅激活已经运行的宿主 App，由宿主保持窗口、标签页和对话选择，无需辅助功能或自动化权限。
- Pi 使用最终稳定结束事件，避免自动重试期间提前显示完成；继续通过结构化元数据过滤 Codex 内部和后台任务。
- 保留原生系统实时活动、可配置完成提醒、英文与简体中文。
- 改用 **DMG** 安装：打开后把 DynamicAgents.app 拖到 Applications，推出映像再启动。本版不提供 ZIP。

**升级：**0.1.x 的更新检测仅识别 ZIP，请手动下载本版 DMG。进入“设置 → Agent Hook → 管理 Agent Hook”更新已有适配器；按需安装 Pi 并执行 /reload，检查 Codex 的 Hook 信任设置。

需要 Apple silicon、macOS 27.3+ 和 Python 3；Pi 需要支持 agent_settled 的扩展 API。发布包在本地构建并上传，仅保留运行必需的 ad-hoc 签名，没有 Developer ID 签名或公证。首次启动被阻止时，可在“系统设置 → 隐私与安全 → 仍要打开”确认。
