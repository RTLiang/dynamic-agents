# Dynamic Agents 0.2.2

## English

Remove the separate Needs Input state from the dashboard, status filter, menu, Live Activity model and localized labels. Permissions and questions stay Running while a turn remains unfinished. Default order is Running → Completed → Idle → Unknown.

Old Hook reports and Live Activity payloads using blocked are converted to Running, including their counts. Completion reminders and Codex verified-user filtering are unchanged.

Update the App and its shared Hook helper in Settings → Agent Hooks. Available as a locally built DMG for Apple silicon, macOS 27.3+.

## 简体中文

移除仪表盘、状态筛选、菜单、实时活动模型及中英文文案中的 Needs Input / 等待输入。权限请求和提问期间，一轮尚未结束的会话统一保持“运行中”。默认排序为：运行中 → 已完成 → 空闲 → 未知。

旧 Hook 记录和实时活动载荷中的 blocked 状态及数量兼容转换为“运行中”。完成提醒和 Codex 用户来源验证保持原有行为。

更新 App 后，在“设置 → Agent Hook”中更新共享 helper。提供本地构建的 DMG，适用于 Apple silicon、macOS 27.3+。
